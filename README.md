# furniture_portfolio_4

> **AURA LIVING** — Space to Live Beautifully.

A spatial room-to-object furniture platform guiding visitors from ambient interior discovery to focused individual piece inspection, materials exploration, and dimension analysis.

## 🚀 Key Features
- **Spatial Storytelling**: Room-to-object transition animations
- **Material & Dimension Visualizer**: Exploded anatomical view and architectural dimension lines
- **Virtual Showroom & Consultation**: Booking appointments and dynamic room configurations
- **Production HTML & Bundle**: Pre-compiled production build included in `dist/`

## 🛠 Tech Stack
- **React 18** + **Vite**
- **Three.js** / **@react-three/fiber**
- **GSAP** Motion Design
- **Tailwind CSS**

## 💻 Quick Start
```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
